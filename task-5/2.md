# Задание 2. Динамическая маршрутизация с BIRD

### Подготовка конфига bird.conf

```
vboxuser@Ubuntu:~# sudo nano /etc/bird/bird.conf
protocol direct {
interface "service_*";

filter export_filter {
    if (net ~ 192.168.14.0/24 && net.len = 32 && ifname ~ "service_*") then {
        accept;
    }
    reject;
} 

protocol rip {
    ipv4 {
        import all;
        export filter export_filter;
    };
    interface "enp0s3" {
        mode multicast;
        update time 30;
    };
}
```

### Анализ конфига

```
vboxuser@Ubuntu:~# sudo systemctl restart bird
vboxuser@Ubuntu:~# sudo birdc show route export rip1
BIRD 2.14 ready.
Table master4:
192.168.14.88/32     unicast [direct1 9:36:42.112] * (240)
dev service_0
```

Таблица master4 - таблица маршрутов, заданная админом системы.

Наш сервис:
- `192.168.14.88/32` - адрес сервиса из задания
- `unicast` - одноадресный трафик (один отправитель, один получатель)
- `direct1` - прямой интерфейс локальной сети
- `9:36:42.112` - время появления
- `240` - приоритетность маршрута (чем меньше, тем предпочтительнее)
