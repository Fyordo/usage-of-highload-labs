# Задание 3. Настройка фаервола/ Host Firewalling

### Создание и проверка правила IPTABLES

```
vboxuser@Ubuntu:~$ sudo iptables -A INPUT -p tcp --dport 8080 -j DROP
[sudo] password for vboxuser:
```
```
vboxuser@Ubuntu:~$ sudo iptables -L -n -v
```

### Отправка запроса через curl
```
vboxuser@Ubuntu:~$ curl http://127.0.0.1:8080
```
Запрос завис, что и свойственно при такой настройке `firewall`
