# Задание 2: Межпроцессное взаимодействие (IPC) с разделяемой памятью

### Анализ шеред-мемори во время запущенной программы на С

```
vboxuser@Ubuntu:~/Desktop$ ipcs -m

------ Shared Memory Segments --------
key        shmid      owner      perms      bytes      nattch     status      
0x4102c992 0          root       666        1024       0
```

### Анализ вывода
Сегмент разделяемой памяти был успешно создан **(shmget)** и имеет нужный размер **(1024 байта)** и права **(666)**.

Но процесс не вызвал **shmat**, и никакие другие процессы к нему не присоединились, счетчик присоединенных процессов **(nattch)** равен 0.
