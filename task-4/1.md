# Задание 1: Systemd

### Содержание systemd unit файла для скрипта

```
[Unit]
Description=Homework Custom Heartbeat Service
After=network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/homework_service.sh
Restart=always

RestartSec=15s
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```
