# Задание 3. Балансировка Layer 4 с  с помощью IPVS

### Запуск dummy интерфейса

```
vboxuser@Ubuntu:~$ sudo ip link add dev dummy1 type dummy
vboxuser@Ubuntu:~$ sudo ip addr add 192.168.100.1/32 dev dummy1
vboxuser@Ubuntu:~$ sudo ip link set dev dummy1 up
```
