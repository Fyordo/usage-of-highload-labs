# Задание 2. DNS Load Balancing с помощью dnsmasq

### Подготовка конфига `dnsmasq.conf`

```
address=/my-awesome-highload-app.local/127.0.0.1
address=/my-awesome-highload-app.local/127.0.0.2
```

### Применение конфига `dnsmasq.conf`

```
vboxuser@Ubuntu:~$ sudo dnsmasq -C dnsmasq.conf -k -p 53 -i 127.0.0.1
```

Чтобы завелось, предварительно выключил `systemd-resolved`

### Анализ вывода

Это означает, что доменное имя `my-awesome-highload-app.local` имеет две записи типа A: 
- С IP-адресом 127.0.0.1
- С IP-адресом 127.0.0.2

Если один из backend-серверов перестанет отвечать, ничего не сломается.
DNS продолжает возвращать обе записи, и, как следствие,
ответственность за обработку ошибок отдаётся клиенту.
