# Задание 1. Создание Server Pool для backend

### Создание папок и индекс-файлов

```
vboxuser@Ubuntu:~$ mkdir backend1
vboxuser@Ubuntu:~$ mkdir backend2
vboxuser@Ubuntu:~$ nano backend1/index.html
vboxuser@Ubuntu:~$ nano backend2/index.html
```

### Создание папок и индекс-файлов

```
vboxuser@Ubuntu:~/backend1$ python3 -m http.server 8081
Serving HTTP on 0.0.0.0 port 8081 (http://0.0.0.0:8081/) ...
vboxuser@Ubuntu:~/backend2$ python3 -m http.server 8082
Serving HTTP on 0.0.0.0 port 8082 (http://0.0.0.0:8082/) ...
```

### Проверка работы

```
vboxuser@Ubuntu:~/backend1$ curl localhost:8081
<h1>Response from Backend Server 1</h1>
vboxuser@Ubuntu:~/backend1$ curl localhost:8082
<h2>*** Response from Backend Server 2 ***</h2>
```
